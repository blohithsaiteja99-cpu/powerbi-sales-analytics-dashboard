# 📊 Power BI Sales Analytics Dashboard

An interactive Power BI dashboard developed to analyze sales performance, customer behavior, product performance, and regional sales trends.

## 🚀 Project Overview

This project transforms raw sales data into an interactive business intelligence dashboard using Microsoft Power BI.

The dashboard provides insights into sales performance, customer purchasing behavior, product categories, payment methods, membership levels, and regional performance.

## 📌 Dashboard Pages

### 1. Executive Sales Overview

The Executive Sales Overview provides a high-level summary of business performance.

Key metrics include:

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Return Rate
- Monthly Sales Trend
- Sales by Category
- Sales by Payment Method
- Sales by State
- Sales by Membership

### 2. Customer Analysis

This page focuses on customer behavior and purchasing patterns.

Analysis includes:

- Sales by Gender
- Average Customer Age
- Average Customer Rating
- Average Previous Purchases
- Average Visit Duration
- Sales by Membership Level
- Orders by Device
- Visit Duration vs Sales
- Previous Purchases vs Sales

### 3. Product & Category Analysis

This page focuses on product and category performance.

Analysis includes:

- Total Sales by Category
- Total Quantity by Category
- Total Discount by Category
- Product Price vs Sales
- Category-wise Sales Contribution
- Average Product Price
- Average Quantity per Order
- Discount Analysis

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze overall sales performance.
2. Identify high-performing product categories.
3. Understand customer purchasing behavior.
4. Analyze regional sales performance.
5. Compare membership-level performance.
6. Identify relationships between customer behavior and sales.
7. Present business insights through interactive visualizations.
